# 会话分栏

在 DSH 主界面里左右并排显示两个会话，各自拥有独立的对话记录、输入框、消息队列与工具视图，互不干扰。

## 功能

- **左右双栏**：一屏显示两个会话，每一栏都完整可用（记录、输入、队列、工具卡片都在），可以分别操作。
- **随时换会话**：每栏顶部是可点击的会话名，展开列表即可切换，列表会显示标题、所属工作区与运行状态。
- **自由调整宽度**：拖动中间分隔条分配左右宽度；双击分隔条恢复为各占一半；分隔条获得焦点后也可以用左右方向键微调。
- **常用操作**：右上角可以交换左右两栏，或关闭分栏回到普通会话；每栏还能把当前会话"在主会话中打开"。
- **智能体团队**：会话带有 Agent Teams 时，栏头会出现团队入口，展开可以查看成员名单与共享任务。点击成员会在当前栏内切换到该成员的会话，点团队负责人则切回负责人，不会跳出分栏。
- **状态记忆**：左右两栏显示哪个会话、分隔条位置都会被记住，重新打开分栏页自动恢复。
- **桌面端细节**：分栏页顶部栏可以拖动窗口；窗口变窄、左侧栏收起时，内容会自动避开 macOS 的窗口按钮，不会互相遮挡。

## 安装

适用于 DSH 桌面端和 Web 版。

### 从 GitHub 安装（推荐）

1. 打开 DSH 左侧的**插件**页面；
2. 点击**添加插件**（或箭头菜单里的**安装第三方插件**）；
3. 在包名输入框填入：

   ```text
   git+https://github.com/B635/dsh-split-view.git
   ```

4. 点击**安装**。安装完成后插件会自动启用，左侧栏出现分栏图标即可使用。如果提示需要重启，重启 DSH 即可。

也可以交给 Agent 安装，在会话中执行：

```text
plugin_manager install_bundle target=git+https://github.com/B635/dsh-split-view.git
```

### 离线安装

在仓库的 Releases 页面下载最新的 `local-dsh-session-split-*.tgz`，拷贝到目标电脑后，在**添加插件**里填入该文件的绝对路径，再点击**安装**。

### 本地目录安装（开发调试）

将仓库克隆到本地，在**添加插件**里填入仓库目录的绝对路径即可。这种方式下修改代码后，需要重新安装或重启 DSH 才会生效。

## 使用

打开分栏页有两种方式：

- 点击左侧栏底部的**分栏图标**；
- 点击会话标题栏右侧的**分栏按钮**，会以当前会话作为左栏打开。

进入分栏页后：

- 点击每栏顶部的会话名，选择该栏要显示的会话；
- 拖动中间分隔条调整左右宽度，双击恢复各占一半；
- 会话带团队时，点击栏头团队入口查看成员与共享任务，点击成员即可在当前栏切换；
- 点击右上角按钮交换左右两栏，或关闭分栏。

## 更新与卸载

- **更新**：在插件页卸载后重新安装最新版即可。
- **卸载**：在插件页关闭或卸载本插件。
- **清理记忆**：如需重置两栏会话与宽度，清除浏览器中本插件的本地数据后重新打开分栏页。

## 兼容性

- 已在 DSH `0.2.1-rc.5`（桌面端）与 `0.2.1-rc.2`（Web 版）上验证通过。
- 纯前端插件，无额外依赖，无需构建步骤，macOS、Windows、Linux 均可使用。
- DSH 后续版本如果调整 Web 界面接口，可能出现兼容问题。遇到异常请在 Issues 中反馈，并附上 DSH 版本号。
